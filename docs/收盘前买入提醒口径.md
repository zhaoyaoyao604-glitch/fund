# 收盘前 10 分钟「买入信号」桌面提醒

## 一、什么时候弹

各市场**收盘前 10 分钟**自动扫一遍自选票，命中就弹一条 Windows 右下角通知（进通知中心，可回看）。

| 市场 | 当地收盘 | 实际弹出时间（北京） |
|---|---|---|
| A 股 | 15:00 | 14:50 起 |
| 港股 | 16:00 | 15:50 起 |
| 美股 | 16:00（美东） | 夏令时 03:50 / 冬令时 04:50 |

- 每个市场一天只弹一次；窗口长度 10 分钟，中途才开机/重启服务也不会漏。
- 周末不跑；节假日靠「今天没有报价」自动跳过，不会弹空通知。
- **一个都没命中就不弹**（不打扰）。想立刻看一次结果，双击 `测试买入提醒.bat`。

## 二、什么算「到了买入条件」

与回测页完全同一套规则（见 `docs/回测规则口径.md`）：

1. 今日实体底 = min(今开, 现价)，实体顶 = max(今开, 现价)，实体高度 = 实体顶 − 实体底
2. 均线：MA3 = (前两日收盘 + 现价) ÷ 3，MA5 = (前四日收盘 + 现价) ÷ 5；昨日 MA3/MA5 用昨日及更早的收盘价算
3. 金叉闸门：**今日 MA3 > 今日 MA5 且 昨日 MA3 ≤ 昨日 MA5**（MA3 当日上穿 MA5）。MA3 死叉下行、或已在 MA5 上方但未再上穿 → 不提醒，**即使实体整体/大部分站上 MA3 也不提醒**
4. 实体条件：**MA3 ≤ 实体底 + 实体高度 × 20%**，且 MA3 < 实体顶（实体至少 80% 的高度站在 3 日线之上，允许均线浅穿实体下沿 20% 以内）
5. 排除：今日箱体与前日箱体**平行**（顶对顶、底对底偏移都 ≤ 前日实体高度 20%）→ 不提醒；今日实体底 ≤ 昨日实体底 → 不提醒

盘中拿不到当日最终收盘价，用**实时报价的现价**代替；历史数据一律取到昨日为止，所以上游当天给不给日 K 都算得出。

## 三、覆盖范围

`cards`（历史模拟仓）与 `cards_live`（实时跟随仓）**两张表的并集**，即两个页面里的自选票都算。
只判信号，不看你现在有没有持仓——空仓和满仓都会提醒。

## 四、已知限制

- 信号用的是盘中现价，**收盘可能变**：14:50 命中、15:00 收盘时条件可能不再成立（也可能反过来）。
- 电脑关机/睡眠、或后端没起来的时候不会提醒。
- 手机收不到，只在本机弹窗。
- 通知里最多列 4 只，超过显示「等共 N 只」；完整明细见 `/api/notify/scan` 接口返回。

## 五、落地位置

- 后端：`server/main.py` 末尾「收盘前 10 分钟买入信号提醒」一节，含 `_remind_loop` 定时任务与 `GET /api/notify/scan` 手动扫描接口
- 通知通道：`server/toast.ps1`（零依赖，调 Windows 自带通知能力，无第三方包）
- 入口：`测试买入提醒.bat`
