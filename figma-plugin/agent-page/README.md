# AGENT 页面 → Figma 导入说明

插件已写好，两步即可在你的 Figma 文件里生成可编辑图层。

## 一、导入插件（只做一次）

1. 打开 Figma 桌面版（推荐）或网页版，打开你要放页面的那个文件。
2. 顶部菜单：`Plugins` → `Development` → `Import plugin from manifest…`
3. 选中本目录的 `manifest.json`，导入成功。

## 二、运行

`Plugins` → `Development` → `AGENT Page Push` → 运行。

运行后会在当前文件里新建一个页面 **「AGENT · agent.html」**，内含两块 1440×900 画板：

- `01 · 首页（Hero 态）`：居中标题 + 底部胶囊输入框 + 提示词 chip
- `02 · 对话态（Chatting）`：同上侧栏与顶栏，改成消息流 + 输入框贴底

原文件已有的页面不受影响（新建页面，不动现有画板）。

## 三、生成的图层结构

每块画板内部按 CSS 结构分组，全部可直接点选、改字、改色、改圆角：

- 背景 Background：底色 + 两团径向光晕 + 顶部弧光
- 侧栏 Sidebar：品牌区 / 搜索框 / 发现应用 / 菜单 Menu（6 项，含 BETA 标签）/ 分组·任务 / 分组·空间 / 用户区
- 顶栏 Topbar：标题 + 在线状态胶囊
- 状态栏 Statusbar：运行中徽标 / 工作区头像 / 通知 / 设备
- Hero 标题区、输入框 Composer（含三个工具胶囊 + 发送按钮）、提示词 chips
- 对话态另有：对话流 Thread（用户气泡 / Agent 头像 / 工具调用标签 / 回复正文）

图标是矢量节点（icon-* 命名），可以直接换颜色或替换。

## 五、可能遇到的情况

- **中文变方块**：说明 Figma 里没有加载到中文字体。插件优先用 Microsoft YaHei，其次 Noto Sans SC、PingFang SC；桌面版一般没问题。
- **想改宽度或加第三块画板**：编辑 `code.js`，`W / H / SB` 三个常量控制画板尺寸与侧栏宽度，`main()` 末尾照抄一段即可加画板。
- **想重新生成**：再运行一次会再新建一个页面，旧页面留着对照或删掉都可以。
